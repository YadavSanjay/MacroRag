# ── Macro RAG — lightweight SERVING image dependencies ───────────────────────
# The served backend (REST API / MCP) is a SEPARATE, lightweight image: it does
# NOT bundle the bge-m3 embedder / bge-reranker (torch). The heavy inference is
# hosted out-of-process by the sister project **RagInference**; the backend
# reaches it over HTTP (RAGINFER_URL / inference.remote_url, default :8799) via
# the RemoteEmbedder / RemoteReranker clients.
#
# Consequently this list DELIBERATELY OMITS the multi-GB ML stack that the full
# requirements.txt carries for local dev / in-process fallback:
#   - FlagEmbedding          (pulls torch; local bge-m3 embed + rerank)
#   - sentence-transformers  (pulls torch; cross-encoder rerank fallback)
#   - playwright             (JS-rendered ingestion fetch fallback)
# All three are imported lazily (embeddings/bge_m3.py, retriever/rerank.py,
# ingest/common/browser.py), so their absence is safe as long as the backend
# uses the remote clients and inference.fallback_local is OFF (see rag.prod.yaml).
